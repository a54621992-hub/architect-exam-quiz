# 建築師高考「營建法規與實務」40天極速衝刺 PWA APP

專技高考建築師「營建法規與實務」零散時間備考專用 PWA 行動應用程式。支援離線單檔執行、跨裝置進度移轉、桌面安裝與全真模擬考。

## 🎯 核心功能

1. **800 題全量題庫與精準法規詳解**：
   - 收錄 105 ~ 114 年高考建築師「營建法規與實務」全真試題。
   - 題題包含：精確法規名稱與條號（`law`）、核心數值關鍵字（`analysis_key`）、選項辨析詳解（`explanation`）。
2. **120 分鐘計時全真模擬考**：
   - 嚴格依照正式高考規格（40 題單選、倒數 120 分鐘、交卷評分與錯題覆盤）。
3. **十大高頻專題特訓**：
   - 防火區劃與避難、無障礙設計、高層建築、建築法規執照、都市計畫與都更、政府採購、危老條例、國土計畫、室內裝修、公寓大廈。
4. **數字翻牌卡（Flashcards）**：
   - 快速建立高頻法定數字神經迴路。
5. **跨裝置進度同步（Sync Code）**：
   - 電腦與手機透過代碼 1 秒移轉刷題進度與錯題本。
6. **PWA 桌面安裝體驗**：
   - 支援 Android Chrome 一鍵安裝、iOS Safari 加入主畫面，全螢幕無干擾運行。
   - 576px 手機視覺比例居中適配。

## 📁 檔案架構與部署

- `index.html`：PWA 主入口頁面（雙行結構化標題、直立緊湊導航按鈕、獨立視圖結構）。
- `styles.css`：核心響應式樣式表（適配極窄螢幕行動端）。
- `questions.js`：800 題題庫與詳解資料庫。
- `flashcards.js`：60 張高頻數字翻牌卡資料庫。
- `app.js`：SPA 狀態機、計時器、及格線動態雷達與同步邏輯。
- `manifest.json`：PWA 應用設定檔（支援 Maskable 圖示與獨立視窗）。
- `sw.js`：Service Worker 快取離線支援（v2.0 Network-first）。
- `bundle.py`：單檔打包腳本，生成可免伺服器離線執行的 `index_bundle.html` 並自動同步至 Google Drive。
