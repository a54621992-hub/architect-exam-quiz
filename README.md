# 建築師高考「營建法規與實務」衝刺刷題 PWA APP

專技高考建築師「營建法規與實務」零散時間備考專用 PWA 行動應用程式。支援離線單檔執行、跨裝置進度移轉、桌面安裝與模擬考。

## 🎯 核心功能

1. **110～114 年歷屆真題 400 題與法規詳解**：
   - 收錄 110～114 年高考建築師「營建法規與實務」試題（每年 80 題），答案已與考選部標準答案／更正答案逐題核對一致。
   - 題題包含：法規名稱與條號（`law`）、核心數值關鍵字（`analysis_key`）、選項辨析詳解（`explanation`）。
   - 考選部「一律給分」題標為 `#`；更正為多個答案均給分者以 `accept` 欄位記錄（113-33、114-27 答 B 或 D）。
2. **今日 30 題（依年份順刷）**：114→110 依題號接續上次進度，每答一題推進一格，14 天刷完 400 題、不漏不重複。
3. **條文命題 200 題**：以 NotebookLM「建築師法規」筆記本（個人帳號）限定 19 份法規條文 PDF 出題；每題附條文逐字原句並經程式比對法規原文，另人工抽查 40 題全對。每回 20 題依序接續，**不混入**每日順刷、專題與模擬考；答錯一樣進錯題本。
4. **20 題迷你模考**：限時 30 分鐘（與正式考試同配速，每題 1.5 分鐘），錯題優先出題。
5. **80 題全真模擬考**：比照正式規格（80 題單選、120 分鐘）。
6. **錯題大屠殺**：答錯自動入庫，連續答對 2 次出庫。
7. **數字翻牌卡（Flashcards）**：59 張，已逐張對照法條原文校正（2026-10-13）。
8. **跨裝置進度同步（Sync Code）**：電腦與手機透過代碼移轉刷題進度、錯題本與兩種順刷進度。
9. **PWA 桌面安裝**：支援 Android Chrome 一鍵安裝、iOS Safari 加入主畫面。

## 📁 檔案架構與部署

- `index.html`：PWA 主入口頁面。
- `styles.css`：響應式樣式表（適配極窄螢幕行動端）。
- `questions.js` / `questions.json`：400 題歷屆題庫與詳解（兩檔內容相同，js 供頁面載入）。
- `nlm_questions.js`：條文命題 200 題（`NLM_QUESTIONS`，id `N001`～`N200`，explanation 末附【條文原句】）。
- `flashcards.js`：59 張數字翻牌卡。
- `app.js`：SPA 狀態機、順刷進度、計時器、及格線雷達與同步邏輯。
- `manifest.json`：PWA 應用設定檔。
- `sw.js`：Service Worker 快取離線支援（Network-first，cache v2.4）。
- `bundle.py`：單檔打包腳本，生成可免伺服器離線執行的 `index_bundle.html`。
